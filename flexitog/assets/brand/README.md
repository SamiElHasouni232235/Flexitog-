# Brand files

Put the RefrigiWear logo here as `refrigiwear_logo.svg` (preferred), `.png`, `.webp` or `.jpg`, then rebuild
with `python tools/build_dashboard.py`. The build embeds it in the page: 300 px wide on the home page,
180 px on the login card, 26 px high in the Home link. Its aspect ratio is kept. Without a file the home
page shows a 300 px placeholder box.
